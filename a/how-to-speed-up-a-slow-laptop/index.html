How to Speed Up a Slow Laptop: 12 Fixes (Free First, Then SSD & RAM)

Quick answer: Most laptop slowness is software, not old age. Start free — disable startup apps (Ctrl + Shift + Esc → Startup apps), free up disk space, and scan for malware. If it's still slow and you're running an old mechanical hard drive, swapping it for an SSD is the single biggest upgrade you can make. If you already have an SSD but stutter with lots of tabs open, add RAM instead.

A slow laptop almost never means you need a new one. Nine times out of ten, the lag comes from too many programs loading at startup, a nearly full disk, or background junk eating your memory — all of which you can fix in a few minutes for free. This guide walks you through the no-cost fixes first, then gives you an honest decision rule for the one question shoppers actually ask: should I add an SSD or more RAM, and which one first?

Heads-up: Windows changes a few menu labels between Windows 10 and Windows 11. The steps below are written for current Windows 11 as of 2026; if a label looks slightly different on your machine, look for the closest equivalent.

Why Is My Laptop So Slow? The 5 Usual Causes

Before you change anything, it helps to know what you're fighting. Almost every slow laptop comes down to one or more of these:

  • Too many startup and background apps. Programs that launch with Windows and quietly run in the background eat CPU and memory before you've opened a thing.
  • A nearly full disk. When your drive is almost full, Windows has no room to breathe, and performance drops. (Source: Microsoft Support.)
  • Malware or bloatware. Hidden malware and pre-installed junk apps consume CPU and RAM and cause slowdowns. (Source: Microsoft Support.)
  • An aging mechanical hard drive (HDD). A spinning hard drive is the single most common bottleneck on an older laptop — slow boot, slow file access, slow everything.
  • Too little RAM. With not enough memory, Windows leans on a "page file" on your disk, which is far slower than real RAM and shows up as lag when you multitask.

The order matters: try the free software fixes first, then look at hardware only if you're still slow.

Free Fixes to Try First (5 Minutes, No Money)

Work down this list in order. The first few clear the most slowdown for zero cost, and every step here comes straight from Microsoft's own performance guidance.

1. Restart properly and close unused apps

Closing the lid puts the laptop to sleep — it doesn't clear anything. A full restart flushes memory and ends stuck processes. After it reboots, close apps and browser tabs you're not actively using. (Source: Microsoft Support.)

2. Disable startup programs

This is usually the single biggest free win. Too many apps launching at boot is the classic cause of a slow startup.

  • Press Ctrl + Shift + Esc to open Task Manager.
  • Click Startup apps in the left menu.
  • Right-click anything you don't need at boot (chat apps, updaters, manufacturer utilities) and choose Disable. (Source: Microsoft Support.)

You're not uninstalling anything — you're just telling it not to launch automatically.

3. Free up disk space

Low disk space can drag down system performance, so clear the clutter:

  • Use Storage Sense (Settings → System → Storage) or the classic Disk Cleanup tool to remove temporary files, caches, and old downloads. (Source: Microsoft Support.)

A good rule of thumb is to keep at least 10–15% of your drive free.

4. Scan for malware and remove bloatware

Malware and potentially unwanted programs quietly hog CPU and memory.

  • Run a scan with Windows Security (Settings → Privacy & security → Windows Security → Virus & threat protection). (Source: Microsoft Support.)
  • Then uninstall pre-loaded junk you never use from Settings → Apps → Installed apps.

5. Turn off background apps and unneeded notifications

Apps allowed to run in the background sip resources even when you're not using them. In Settings → Apps → Installed apps, click an app's three-dot menu → Advanced options, and set background permission to Never for ones you don't need live.

6. Adjust visual effects for best performance

The animations and shadows look nice but cost a little performance on older hardware.

  • Click Start, type "Adjust the appearance and performance of Windows," open it, and on the Visual Effects tab choose Adjust for best performance. (Source: Microsoft Support.)

7. Update Windows and your drivers

Updates often include performance and stability fixes, and a buggy driver can quietly slow things down.

  • Go to Settings → Windows Update → Check for updates and install what's offered. (Source: Microsoft Support.)

One honest note: ignore the old internet tips about ReadyBoost or manually editing the page file / virtual memory. Microsoft's official performance guidance does not recommend those for modern systems, and the gains are negligible at best. Skip them.

If you've done all seven and your laptop is still slow, the bottleneck is probably hardware — and that's where a cheap upgrade can genuinely transform an old machine.

SSD vs RAM Upgrade: Which Speeds Up an Old Laptop More?

Here's the decision rule, in plain terms, before you spend a dollar:

If your laptop still has a mechanical hard drive (HDD), an SSD is the single biggest, most transformative upgrade you can make — do that first. If you already have an SSD but the laptop stutters when you multitask (many tabs, several apps at once), RAM is the smarter first upgrade.

Match the fix to the symptom:

Your symptom Likely bottleneck Best first upgrade
Slow boot, slow to open files/apps, you still have an HDD The mechanical hard drive SSD
Boots fine (already on SSD) but lags with many tabs/apps Not enough RAM RAM
Both: old HDD and only 4 GB RAM Disk first, then memory SSD first, RAM second
Random freezes, fan roaring, but plenty of RAM and an SSD Possibly malware/thermal, not hardware Re-check the free fixes above

Why SSD usually wins for an HDD laptop: swapping a spinning hard drive for a solid-state drive is repeatedly described by hardware outlets as the most dramatic speed upgrade available — boot and app-launch times typically drop from tens of seconds to just a few. An SSD also draws less power than an HDD, so battery life often improves a little too. (Sources: Tom's Hardware, How-To Geek, MakeUseOf, Dignited.) Exact numbers vary by machine, so treat any "boots in 12 seconds" claim as typical, not guaranteed.

Why RAM matters once you're on an SSD: with too little memory, Windows offloads data to a page file on your disk, which is far slower than real RAM. Adding memory fixes the multitasking lag that an SSD alone can't. (Sources: MiniTool, How-To Geek.)

How Much RAM Do You Need? (8GB vs 16GB vs 32GB)

Buying more memory than you'll use is wasted money. Match the capacity to how you actually use the laptop:

RAM Good for Notes
8 GB Browsing, email, word processing, streaming The practical minimum for everyday use today
16 GB Heavier multitasking, lots of browser tabs, photo editing The sweet spot for most people in 2026
32 GB+ Video editing, software development, modern gaming Only worth it for genuinely heavy workloads

(Sources: Crucial, How-To Geek.) For most people upgrading an older laptop, 8 GB → 16 GB is the upgrade that feels best for the money.

Can Your Laptop Actually Be Upgraded? (Check Before You Buy)

This is the step people skip and regret. Many modern thin-and-light laptops have RAM and/or storage soldered to the board — meaning they can't be upgraded at all. Always confirm before you order parts.

  • Run a free scan with the Crucial System Scanner (or look up your exact model with Crucial Advisor) to see what RAM and SSD your laptop supports. CPU-Z is another free tool that reads your current memory type and speed. (Sources: Crucial, Newegg.)
  • The scan tells you three things you need: the maximum RAM, the type and speed of module to buy, and whether the storage slot is upgradeable at all.

If the scan shows soldered, non-upgradeable RAM, that's your answer — no part will fix it, and a replacement laptop is the only path.

Last Resort: Reset or Clean-Install Windows

If the machine is buried under years of bloat and nothing above helps, a fresh Windows install wipes the slate clean and often feels like a new laptop.

  • Back up everything first — this erases the drive.
  • Go to Settings → System → Recovery → Reset this PC, or do a full clean install from a Windows installation USB for the cleanest result.

Treat this as a genuine last resort, and confirm your backup is complete before you wipe anything — there's no undo.

A quick warning: avoid downloading "PC booster," "registry cleaner," or "speed up your PC" utilities. Most do little, some bundle junk or adware, and the built-in steps in this guide do the real work for free. Skip them.

FAQ

Will an SSD make my old laptop faster?
Yes — if you still have a mechanical hard drive, swapping it for an SSD is usually the single biggest speed upgrade you can make. Boot and app-launch times typically drop dramatically, and battery life can improve a bit too.

Should I upgrade RAM or SSD first?
If you still have an HDD, do the SSD first — it's the bigger bottleneck. If you already have an SSD but the laptop lags when you multitask, add RAM first. If you have both an old HDD and only 4 GB of RAM, do the SSD, then the RAM.

How much RAM do I need for a laptop?
8 GB is the practical minimum for everyday browsing and office work, 16 GB is the sweet spot for most people, and 32 GB or more is only worth it for video editing, development, or modern gaming.

Why is my laptop slow after a Windows update?
Right after an update, Windows often re-indexes files and updates drivers in the background, which can cause temporary slowdown. Restart, let any pending updates finish, and update your drivers — it usually settles within a day.

Can all laptops be upgraded?
No. Many thin, modern laptops have RAM and/or storage soldered to the board and can't be upgraded at all. Run the free Crucial System Scanner (or CPU-Z) to check before you buy any parts.

The Bottom Line

  • Start free: restart, disable startup apps (Ctrl + Shift + Esc → Startup apps), free up disk space, scan for malware, and adjust for best performance. That fixes most slow laptops in minutes.
  • Still slow? Match the upgrade to the bottleneck: HDD → add an SSD first (the biggest single boost); already on an SSD but multitasking lags → add RAM (8 GB → 16 GB is the sweet spot).
  • Check upgradeability first with the free Crucial System Scanner — many modern laptops have soldered parts — and always back up before you open anything.

Run the free fixes in order, and you'll likely have a noticeably snappier laptop before you ever reach for a screwdriver. If hardware really is the limit, a sub-$100 SSD or RAM kit can give an old machine years more life.
